# Ammonia–Hydrogen Staged Combustion

Cantera-based, zero-dimensional study of ammonia–hydrogen combustion in two
perfectly stirred reactors (PSRs). The primary stage receives fuel and a
controlled fraction of the air; the secondary stage receives the remaining
air. The study sweeps fuel composition, primary-stage equivalence ratio, and
residence time, then compares outlet temperatures, emissions, and fuel slip.

## Model and parameter sweep

The fuel is a one-mole NH₃/H₂ blend. For ammonia mole fraction \(x\), the
stoichiometric oxygen requirement is

\[
n_{\mathrm{O_2,stoich}} = 0.75x + 0.5(1-x).
\]

The air split is set by the primary equivalence ratio \(\phi_1\) and fixed
overall equivalence ratio \(\phi_{\mathrm{overall}}=0.9\):

\[
n_{\mathrm{air,primary}} = \frac{n_{\mathrm{air,stoich}}}{\phi_1},
\qquad
n_{\mathrm{air,total}} = \frac{n_{\mathrm{air,stoich}}}{\phi_{\mathrm{overall}}}.
\]

The difference is added before the secondary PSR. Both stages use the same
nominal residence time. The main notebook evaluates 11 NH₃ fractions
(0–100%), 11 primary equivalence ratios (1.0–2.0), and five residence times
(20–100 ms), for 605 cases. It records convergence status and checks the
resulting overall equivalence ratio.

These are idealized 0-D reactor calculations, not spatially resolved burner
predictions. Correlations, response surfaces, and reaction-path rankings are
descriptive analyses and should not be interpreted as proof of causality.
NOx is reported as NO + NO₂; N₂O is tracked separately.

## Setup

Python 3.10 or later is recommended. Create and activate a virtual environment,
then install the dependencies:

```bash
python -m venv .venv-btp
source .venv-btp/bin/activate    # Windows: .venv-btp\Scripts\activate
python -m pip install -r requirements.txt
python -m ipykernel install --user --name btp --display-name "Python (BTP)"
```

Select the **Python (BTP)** kernel, then open `full_results_modified.ipynb` in
Jupyter and run it from the repository root. The notebook expects
`TamaokiNH3.yaml` in the current working directory.
The full parameter sweep performs hundreds of integrations and may take
significant time. Generated CSV files are written to the repository root.
To execute it from a terminal and save an executed copy:

```bash
python -m nbconvert --to notebook --execute \
  --ExecutePreprocessor.kernel_name=btp \
  full_results_modified.ipynb --output full_results_executed.ipynb
```

### Recommended notebook flow

1. Run the setup and model-definition cells in `full_results_modified.ipynb`.
2. Run the single-case smoke test and confirm it converges.
3. Run the full sweep and inspect the convergence and equivalence-ratio checks.
4. Continue through the plots and quantitative analyses; optional solver
   verification is disabled by default.
5. Run `reaction_paths.ipynb` independently to generate diagrams for the
   selected case. It imports the shared model settings and solver helpers from
   `staged_combustion.py`.

Reaction-path rendering additionally requires Graphviz (`dot`) on `PATH`.
Install it with `brew install graphviz` on macOS, or
`conda install -c conda-forge graphviz` in a Conda environment.

## Outputs

The main notebook exports the sweep and derived analysis tables as CSV files.
The tracked CSVs are result snapshots; rerunning the notebook can replace them.
Plots and reaction-path diagram images are generated by the notebooks and are
not tracked.

## Reproducibility notes

- The mechanism filename, inlet conditions, air composition, and sweep settings
  are defined near the beginning of the main notebook.
- Failed integrations are identified by their `Status`; do not treat numerical
  failure as evidence of physical extinction or blow-off.
- The NH₃/H₂ slip and conversion fields follow the definitions in the notebook;
  consult the calculation cells before using them as mass-flow-based
  conversion measures.
- Reaction-path diagrams depend on the chosen case, element, thresholds, and
  Cantera/Graphviz versions.
